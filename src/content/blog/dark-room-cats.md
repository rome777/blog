## 💡 게임 규칙 & 조작

| 조작 | 동작 |
| --- | --- |
| **마우스 이동** | 커서 주변을 손전등으로 비춥니다 |
| **마우스 클릭** | 숨어 있는 고양이를 발견했을 때 클릭해 포획 |
| **마우스 휠** | 손전등 반경 조절 (95px ~ 280px) |
| **키보드 R** | 처음부터 다시 시작 |
| **모바일 터치** | 화면을 끌면 손가락 살짝 위쪽이 밝아집니다 |

### 🔦 손전등의 딜레마: 크기 vs 밝기
마우스 휠을 돌리면 손전등 빔의 크기를 자유롭게 바꿀 수 있습니다.
- 반경을 넓히면 방을 한 번에 넓게 훑을 수 있지만, 조명이 희미해져 세밀한 윤곽을 알아채기 어렵습니다.
- 반경을 좁히면 아주 쨍하고 밝아지지만, 좁은 구역만 보입니다.
- 고양이가 손전등 가장자리에 살짝 걸치면 **눈이 아주 짧게 반짝**입니다. 찰나를 포착했다면 그 주변을 집중 수색해야 합니다!

## 🐈 숨어 있는 다섯 마리의 개성

1. **치즈 (소파 위, 난이도 ★)**: 딱히 숨을 생각이 없어 보입니다. 그냥 푹신한 소파 위에 편하게 웅크리고 있습니다.
2. **깜장 (책장 칸 안, 난이도 ★★)**: 검은 털이 어둠에 완전히 묻힙니다. 빛을 비추면 노란 눈동자만 반사됩니다.
3. **삼색 (커튼 뒤, 난이도 ★★★)**: 커튼 뒤로 쏙 숨었지만, 꼬리 끝을 감추지 못했습니다. 자세히 보면 꼬리가 살랑살랑 흔들립니다.
4. **회색 (러그 위, 난이도 ★★★★)**: 바닥 러그와 털 색깔이 거의 완벽하게 일치합니다. 색이 아니라 고양이 특유의 실루엣으로 찾아내야 합니다.
5. **하양 (천장 조명 갓 위, 난이도 ★★★★★)**: 아무도 위를 쳐다보지 않는다는 심리를 역이용해, 전등 갓 위에 당당히 올라가 있습니다.

## 🛠️ 기술적 구현: 어둠을 뚫는 캔버스 블렌딩

이 게임 역시 의존성 없이 `index.html` 단일 파일로 동작합니다. 핵심은 **Canvas 2D의 합성 모드(composite operation)**입니다.

```javascript
// 어둠 캔버스에 짙은 어둠을 먼저 채웁니다.
darkCtx.fillStyle = 'rgba(4, 5, 9, 0.978)';
darkCtx.fillRect(0, 0, width, height);

// 손전등 위치를 destination-out 모드로 도려내어 투명하게 만듭니다.
darkCtx.globalCompositeOperation = 'destination-out';
const grad = darkCtx.createRadialGradient(x, y, 0, x, y, radius);
grad.addColorStop(0, 'rgba(0, 0, 0, 1)');
grad.addColorStop(1, 'rgba(0, 0, 0, 0)');
darkCtx.fillStyle = grad;
darkCtx.beginPath();
darkCtx.arc(x, y, radius, 0, Math.PI * 2);
darkCtx.fill();

// 본래의 방 캔버스 위에 도려낸 어둠 레이어를 덮어씌웁니다.
mainCtx.drawImage(darkCanvas, 0, 0);
```

방 캔버스 자체에서 지우개를 쓰면 가구와 벽지까지 지워져버리기 때문에, **방을 그리는 캔버스와 어둠을 다루는 별도 레이어를 분리**한 뒤 `destination-out`으로 구멍을 뚫어 덮는 방식으로 자연스러운 조명 효과를 완성했습니다.

또한 논리 좌표를 `1600 × 900` 레터박스 방식으로 고정하여 어떤 모니터나 스마트폰 비율에서도 히트박스가 어긋나지 않도록 처리했습니다.
