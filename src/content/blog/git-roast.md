## 💡 주요 기능 & 재미 포인트

### 1. 취향대로 고르는 두 가지 맛
- **🌶️ 매운맛 팩폭 (Roast Mode)**
  - 작심삼일의 흔적, 벼락치기 잔디 심기, `Update README.md`의 향연을 가감 없이 털어냅니다.
  - "README 오타 고치려고 태어난 깃허브 봇이신가요?", "커밋 주기가 흡사 간헐적 단식 수준" 같은 현실 풍자를 날려줍니다.
- **🍵 순한맛 조언 (Advice Mode)**
  - 팩폭 대신, 취업이나 이직을 앞둔 주니어 개발자 관점에서 커밋 메시지 컨벤션, 코드 리뷰 흔적, 문서화의 아쉬운 점을 다정하게 코칭해 줍니다.

### 2. 한눈에 보는 5대 역량 레이더 차트
단순히 웃고 넘기는 텍스트에 그치지 않고, 수집된 깃허브 활동 데이터를 기반으로 다각도 역량을 정량화합니다.
- **커밋 활동성**: 빈도와 주기성
- **지속성**: 꾸준히 유지되는 스트릭의 진정성
- **문서화**: README, 이슈, PR 템플릿 충실도
- **기술 다양성**: 사용하는 스택과 언어의 스펙트럼
- **스타/인지도**: 오픈소스 기여도 및 커뮤니티 반응

### 3. 공유하고 싶은 결과 카드 (Image Export)
생성된 분석 카드는 `html-to-image` 라이브러리를 통해 고화질 PNG 이미지로 즉시 다운로드하거나 SNS에 자랑(혹은 자폭)할 수 있습니다.

## 🛠️ 기술 스택 & 개발 이야기

- **프레임워크**: Next.js 14 (App Router) + TypeScript
- **스타일링**: Tailwind CSS
- **데이터베이스 & 인증**: Supabase (PostgreSQL, Auth, SSR 지원)
- **배포 환경**: Vercel

### 프롬프트와 페르소나 설계
AI 분석의 핵심은 **"기분 나쁘지 않으면서도 인정할 수밖에 없는 디테일한 팩폭"**입니다.
단순히 "너 못해" 식의 악플이 되지 않도록, 실제 깃허브 API에서 가져온 커밋 메시지 단어 빈도, PR 머지 비율, 시간대별 커밋 분포(새벽 커밋 몰림 현상 등)를 컨텍스트로 전달해 **"와, 이걸 어떻게 알았지?"**라는 탄성이 나오도록 프롬프트를 튜닝했습니다.
