컨텍스트 관리: 남길 정보와 다시 찾을 정보

정보 매몰(Lost in the Middle) 방지 & 토큰 최적화
📊 컨텍스트 선별 파이프라인 흐름도
과도한 누적 (Unmanaged) 해결률 15.0%

빌드 실패 로그, 긴 에러 메시지 전체를 대화에 그대로 쌓아두는 방식. 토큰 비용만 급증하고 모델이 중간 단서를 놓칩니다.

최근 5개 관찰 유지 (SWE-agent 공식) 해결률 18.0% (+3.0%p)

최근 5개의 관찰만 상세히 남기고 이전 관찰은 축약하여 집중도를 극대화. 해결률이 3.0%p 상승했습니다.

연구·벤더 기법 핵심 원리 및 시각화 요약 출처 / 벤치마크
최근 5개 관찰 유지 (SWE-agent) 직전 5개의 도구 호출·실행 결과는 원문을 보존하고, 그 이전의 긴 로그는 1줄로 압축하여 중요한 단서가 묻히는 현상(Lost in the Middle)을 완벽 방지 NeurIPS 2024 (+3.0%p)
코드 목차·색인 지도 (Aider Repo Map) 수천 줄의 코드 본문 전체를 대화에 덤프하지 않고, 함수·클래스 선언부만 추출한 '상세 목차 지도(1000토큰 내외)'만 제공하여 에이전트가 필요한 파일만 정확히 열도록 유도 Aider 공식 설계 문서
RAG vs Long-context 토큰 예산이 충분하다면 긴 원문을 통째로 전달하는 것이 분할 검색보다 성능 우수. RAG의 본질적 가치는 성능 향상이 아닌 '비용 및 지연시간 절감' EMNLP 2024 학술 논문
5

경험·스킬 축적: 지난 실행을 다음 실행에 쓰기

컴파운드 엔지니어링 & 3계층 피라미드
🏛️ Google Research WikiSkill (2026) 3계층 사다리꼴 피라미드 Qwen-27B 정확도: 39.4% → 63.3% 폭등 (+23.9%p)
1. 원문 궤적

검토에 가장 완벽하나 너무 길어 프롬프트 주입 불가.

2. 요약 (Summary)

빠르고 가볍지만, 중요한 예외 조건 누락 위험 존재.

3. 인사이트 (ExpeL)

검색 연동 우수하나(WebShop 0.701), 착각 오염 위험.

4. 코드 스킬 (Voyager)

재사용성 극대화. 구형 API 맹목 반복 주의.

⚠️
메모리 오염(Memory Poisoning) 방지: 에이전트 자율 요약 금지 → 명확한 테스트 실패/정정 증거가 있을 때만 수정하고, 틀린 항목은 삭제 대신 취소선(폐기 표시)을 그어 실수를 방지합니다.

성찰: 실패 기록에서 다음 행동 고치기

막연한 반성문 ❌ → 구체적 다음 행동 1줄 ⭕
🔄 Reflexion 언어 피드백 루프
나쁜 성찰 (추상적 결론) MBPP 점수 하락
"테스트 케이스를 꼼꼼하게 검토하지 못했다."
"검색이 부족했다. 다음엔 더 많이 찾아보자."

→ 다음 턴에서 모델이 어떤 코드를 쳐야 할지 전혀 알려주지 못함.

좋은 성찰 (검증할 행동 지침) HotpotQA +8%p
[실패] 할인 함수가 할인액(2,000)을 반환함
[다음 행동] return price * (100 - p) / 100 으로 수정

→ 에이전트가 다음 번에 어떤 파라미터를 고쳐야 하는지 1초 만에 판단.

최대 3개 제한

과거 반성은 최근 1~3개만 주입해야 토큰 절약 및 집중 유지.

성공 시 스킬 승격

'다음 행동'으로 2~3회 연속 통과되면 공식 스킬(SKILL.md)로 이관.

하지 말 것 대신 '할 것'

"~하지 마라"는 금지어 대신 "~하라"는 구체적 실행 지침 작성.
